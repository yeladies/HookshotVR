# Frozen game-depth calibration build

This is a local diagnostic build for the first headset check of game-derived 3D
surfaces, stereo, head movement and provisional world scale. It is a frozen capture,
not live native game stereo. It has no gameplay input or audio. It cannot reveal
surfaces hidden in the source view: black regions and disocclusion holes are expected.
The ongoing native renderer work remains separate.

## Local use

The prepared private build is under `work/headset-preview/`. Connect Quest 3 through
Virtual Desktop, then run `Probar-en-Quest.cmd`. It presents a projection layer with
independent runtime poses/FOVs for each eye for 60 seconds. The launcher allows at
most 90 seconds including startup/closure. Move the head slightly to inspect parallax,
look at the ground and nearby objects, and judge whether the scale feels natural.
The initial camera retains the game's third-person position. The headset's initial
yaw anchors the scene in LOCAL space; later head movement changes the viewing camera.
A LOCAL reference-space change suppresses frames until the new origin time and
reanchors. Invalid tracking poses are rejected.

The same source launcher is `vr/run-depth-preview.ps1 -Seconds 60`. The prepared
folder contains its own executable, mesh, launcher and hashes; the stable game is
not needed while this viewer runs. **That folder contains private game-derived
geometry/colors. Do not upload or distribute it.** Only the authored capture/viewer
code, shaders, tests and documentation belong in the public repository.

## Capture and reconstruction

`vr/run-game.ps1 -DepthSceneCapture -SnapshotStableSaves -LoadTestSave -Seconds 150`
runs the separate game copy headlessly with audio/XR off. It arms a single capture
at 80 seconds. The candidate color/depth/projection/view must come from a pinned
primary-camera match in the same renderer frame and unchanged texture generation.
At the known gameplay-upscale dispatch, a resolved sampled image must match that
candidate's color identity. No additional texture lookup/import or game update is
performed. Both original images remain GENERAL; explicit dependencies order two
readback copies. The allocation is capped at 16 MiB and retired only after actual
queue completion. Unknown/device-changed completion retains storage.

The capture records the **actual sampled color view format**, not only the image's
storage format: this scene uses RGB9E5 (123) over B10G11R11 storage (122). Interpreting
those bits as B10G11R11 gives false colors. V2 records width, height, that format,
row-major projection/view, raw color and D32 depth. The source GL depth is reconstructed
from Vulkan [0,1] by `2*d-1`; pixel rows are top-down. View-space points are rotated
back to level world axes and aligned to the source camera's horizontal heading.
Default scale is provisionally one metre per game unit, consistent with the captured
0.1-unit near plane; headset perception remains to be checked.

`vr/depth_scene_mesh.py CAPTURE MESH --scale 1 --step 6` creates a bounded triangle
mesh. Invalid/far depth and discontinuity-crossing triangles are rejected. The mesh
contains source colors decoded to linear light for the sRGB target. Authored GLSL
shaders are regenerated by `vr/generate_depth_scene_shaders.py --compiler PATH`;
no game shader is included in the viewer. The GPU renderer has per-eye D32 attachments,
real perspective projection and depth testing, and a fixed room-space anchor.

## Verification on 2026-11-13

Windows RTX 2060 SUPER, native capture fingerprint `38d6a5db`, ABI18. A 150-second
private-save capture completed at 1152x648 with sampled view format123. The actual
viewer/shaders rendered both cameras offscreen without creating an XR session:
583489 non-black pixels across the two 800x600 outputs and 257604 differing stereo
pixels. Local image inspection confirmed recognizable scene geometry and corrected
colors. These counts test rendering and disparity, not headset perception or FPS.
All 77 VR tests pass, including reconstruction bounds, both color formats, source
shader hashes and eye-pose matrix checks. The inherited suite reports 357 passed,
5 known baseline/environment failures and 59 skipped in 294 seconds. A separate
default-off startup and all 19 stable installation hashes were checked. Linux/AMD
and the new mode's headset perception remain untested until the user check.
