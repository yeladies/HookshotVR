# Isolated native classic transport

## English

This explicitly gated offscreen experiment extends private per-eye forward depth to a selected direct vertex/fragment draw, including indexed draws. It is not a complete world render or a headset build. The 256-program private capture contains 224 observed direct draws across 45 classic programs with the required opaque source state; these counts are planning evidence, not authorization to replay an old capture.

`HSVR_NATIVE_CLASSIC_TRANSPORT_V1` is separate from the old classic colour and task/mesh protocols. It requires current-process module identities, exact vertex/fragment stage mapping, reviewed read-only private-root effects and observed primary vertex transform reads. Global/shared writes, unsupported stages and incomplete effect review remain rejected. Unknown camera tails are copied GPU-verbatim as in the isolated mesh transport experiment; this does not certify complete camera/root read semantics.

The experimental flags `RX_VK_XR_NATIVE_CLASSIC_TRANSPORT_PROBE` and `RX_VK_XR_NATIVE_CLASSIC_FORWARD_DEPTH_PROBE` require native-eye colour mode and reject mesh mode. Source geometry remains direct triangles only, with the existing count/index/instance limits. Preliminary admission requires an opaque depth-tested `EQUAL` source with writes disabled and blending disabled; actual post-draw dynamic state is checked again. Fragment modes must be known and compatible with late native depth writes. Exact submitted-camera identity and freshness requirements are unchanged.

Both eyes use the same submitted geometry/resources and their validated matrices, preserving near/far coefficients. Private depth is cleared to the far endpoint and written with the direction-correct comparison. The unchanged controls, native colour and actual D32 depth must be verified together. Source depth state, root and descriptors are restored. The existing bounded four-set copy path supports ordinary classic descriptors only in the explicit forward experiment; original push and ordinary descriptor limits remain unchanged elsewhere. Protocol limits remain 32 programs/8192 bytes. Recorder and root allocations keep their separate existing budgets.

All 197 VR checks, eight renderer syntax checks and four affected inherited resource/query checks pass. The recorder test now covers direct/indexed classic commands, push/ordinary descriptor restoration, signed indexed offsets, depth ordering and completion-gated retirement. Actual-game validation of this classic colour/depth experiment is pending. The preceding mesh surface proof and route inventory remain separate observations.

## Source coverage diagnostic / Diagnóstico de cobertura original

**English.** The 150-second private horizontal and vertical runs on source `7656a9e1` remain inconclusive: the original selected colour draw changed zero reference pixels, although the vertical run produced 2649/2624 private colour pixels with matching per-eye D32 writes and 3158 eye-pair differences. These numbers do not prove correct scene coverage. Original installation and save hashes were preserved. No headset test is ready.

The optional `RX_VK_XR_SOURCE_COVERAGE_PROBE=1` diagnostic measures whether the exact selected direct classic source draw passes its original depth/stencil tests. It allocates one private occlusion query, resets outside rendering, begins immediately before the exact indexed/non-indexed command, and ends inside the original render pass before all private draws. It refuses to overlap the game's occlusion query. Serial, queue recording, program and command-buffer identity must match. Reads occur only after known queue completion, with availability and without WAIT or PRECISE requirements; zero, unavailable and nonzero results remain distinct. Query resources use the recorder's existing completion-gated lifetime. The result is diagnostic metadata only: it does not turn an unchanged reference into a successful stereo proof, change depth/camera parameters, or enable complete-world replay. It is off by default.

**Castellano.** Las pruebas privadas horizontal y vertical de 150 segundos con `7656a9e1` siguen siendo inconcluyentes: el dibujo de color original seleccionado cambió cero píxeles de referencia, aunque la vertical produjo 2649/2624 píxeles privados con escritura D32 por ojo y 3158 diferencias entre ojos. Esto no demuestra la cobertura correcta de la escena. Se conservaron los hashes de instalación y partidas originales. Aún no hay una prueba de visor lista.

El diagnóstico opcional `RX_VK_XR_SOURCE_COVERAGE_PROBE=1` mide si el dibujo clásico directo seleccionado supera las pruebas de profundidad/stencil originales. Usa una consulta privada, reiniciada fuera del renderizado, iniciada justo antes del comando original y terminada dentro de su pasada antes de los dibujos privados. Evita solaparse con consultas de oclusión del juego y exige identidad exacta de dibujo, grabación, programa y buffer de comandos. Solo lee tras completar la cola GPU, sin espera y distinguiendo cero, resultado no disponible y cobertura positiva. Sus recursos se liberan con el resto del recorder tras completar GPU. Solo añade información: no convierte una referencia sin cambios en una prueba estéreo válida ni cambia cámara o profundidad. Está desactivado por defecto.

## Bounded visibility qualification / Selección previa acotada

English: the first `127f8ed8` actual-game source query returned available with zero samples, matching its unchanged original image. Its private forward eyes still wrote coincident colour/depth. This establishes absence of passing source samples for that particular selected draw, not absence of all classic world geometry. Nine installation and fourteen original save hashes remained unchanged.

The additional opt-in `RX_VK_XR_QUALIFY_SOURCE_COVERAGE=1` samples candidate original direct draws before allocating private eye images, UBO copies or page roots. It requires the existing classic/source-coverage flags and unchanged current-process shader/preflight checks. At most one query is in flight, 32 program identities, eight observations per program and 256 observations total. Only an available nonzero result supplies a program/ordinal selection hint; it cannot approve a shader or make an unchanged image pass. The subsequent full recorder independently measures the exact source again and retains every original image, camera, root and depth verification. This new selection path has not yet been tested in the actual game.

Castellano: la primera consulta real `127f8ed8` devolvió un resultado disponible con cero muestras, coincidiendo con la referencia original intacta. Los ojos privados sí escribieron color/profundidad. Demuestra ausencia de muestras que superaran las pruebas en ese dibujo concreto, no ausencia de toda la geometría clásica. Permanecieron idénticos nueve hashes de instalación y catorce de partidas.

La opción adicional `RX_VK_XR_QUALIFY_SOURCE_COVERAGE=1` mide candidatos originales antes de reservar imágenes, copias de cámara o raíces privadas. Exige las opciones clásicas existentes y las mismas comprobaciones de shaders y estado del proceso actual. Limita a una consulta en vuelo, 32 programas, ocho observaciones por programa y 256 en total. Solo una cobertura positiva disponible aporta una pista de programa/ordinal; no autoriza shaders ni convierte una referencia intacta en éxito. El recorder completo vuelve a medir el dibujo exacto y conserva todas las verificaciones previas. Esta selección aún no se ha ejecutado en el juego real.

The `3a5490a3` cold/warm runs each found one available positive source observation (24222/24242 samples), but neither recorded a full private classic draw. A visible program/ordinal can cease to satisfy fresh descriptor/camera admission before reuse. Selection hints now expire after eight source frames when no full recorder is active, and recorder-creation rejection clears the hint immediately. This prevents an unusable hint from monopolizing the bounded diagnostic; it does not relax descriptor freshness or stereo verification. Actual-game validation of the expiry change remains pending.

Las pruebas fría y con caché `3a5490a3` encontraron una observación positiva cada una (24222/24242 muestras), sin llegar a grabar un dibujo clásico privado completo. El programa/ordinal visible puede dejar de cumplir los requisitos de cámara/descriptores frescos antes de reutilizarse. La pista ahora caduca tras ocho fotogramas de origen sin recorder activo y se borra si su creación se rechaza. Evita bloquear la selección manteniendo los requisitos de frescura y verificación estéreo. Falta validar este cambio de caducidad con el juego real.
